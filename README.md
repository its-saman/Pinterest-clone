📌 **Pinterest Clone** (Backend Focused)
This is a Pinterest-like application built primarily to practice backend development using Node.js, Express.js, MongoDB, and EJS. The project implements core features such as user registration, authentication, profile management, and image post uploads.

⚙️ This version focuses on the backend functionality. Styling and UI enhancements will be added in future updates.

💻 Tech Stack
Backend: Node.js, Express.js
Database: MongoDB (with Mongoose)
Authentication: Passport.js, Connect-Flash
Templating Engine: EJS

🚀 Features
User Sign-Up & Login
Profile Page with Uploaded Posts
Image Upload with Captions
Authentication using Passport.js
Flash Messages for Login Feedback
Session Management
MongoDB Integration using Mongoose
Data Association: Users linked to their posts

🛠️ Development Process
Initialized the project using Express Generator for a well-structured setup.
Installed key packages like:
mongoose for MongoDB integration
passport.js for authentication
connect-flash for flash messaging
Designed the database with AI assistance for scalability.

Created:
User Schema – handles user credentials
Post Schema – stores image URLs and captions

Implemented routes for:
/register
/login
/upload
/profile
/logout

Linked users with their uploaded posts via Mongoose associations.
Integrated session and login error feedback using Passport and flash messages.
